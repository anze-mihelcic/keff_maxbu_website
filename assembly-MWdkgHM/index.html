Assembly Mwdkghm: correlation between keff and maxbu

What this plot shows

Each point represents one candidate design collected from the fitness files across all included generation folders for this calculation. The plot helps assess whether the two displayed quantities tend to change together.

Loading candidate summary…

X axis
keff. The effective neutron multiplication factor, keff, describes the balance between neutron production and loss.
Y axis
Cycle length [MWd/kgHM], using the units configured for this calculation.
Each point
A single candidate. Hover over it or tap it to see its candidate name, generation, fuel types, coordinates, and source location.
Fit line
A least-squares linear fit through the candidates currently visible after filtering.
Pearson r
Measures linear association from −1 to +1. Values near ±1 indicate a stronger linear relationship; values near 0 indicate little linear association.
Spearman rho
Measures rank-based monotonic association, so it can detect a consistently increasing or decreasing trend that is not perfectly linear.
How to use the interactive controls
  • The four f_type selectors filter fuel regions independently. A candidate must satisfy every specific selection; any leaves that region unrestricted.
  • Color by can show generation, enrichment, or uranium ratio. For enrichment or uranium ratio, select a fuel region and a specific fuel type for that same region.
  • Draw selection lets you draw a closed loop around points. The corresponding chromosomes can then be copied or downloaded.
  • Download shown coordinates exports only the candidates visible under the current filters.
  • The candidate count, correlations, and fitted line update automatically when filters change.

Correlation describes association, not causation. Outliers, repeated candidates, generation history, and other design variables can influence the observed relationship.

Hover over or tap a point for details, or draw a closed loop to select several candidates. Point color indicates generation.

On a phone, swipe horizontally across the chart to inspect the full plot. To select points, tap Draw selection first and then draw the loop with one finger.
